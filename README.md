# ## Sales prediction using Linear Regression predicting sales from TV advertising spend
This model predicts sales based on the money spent on different platforms for marketing. 

Problem Statement:- The goal was to build a predictive model that estimates sales based on the money spent across different marketing platforms.

Approach:-
 * Utilized simple linear regression to analyze how TV ad spend influences sales.
 * Explored the data to uncover trends and insights that could help optimize marketing budgets. 

Outcome:-
 The linear regression model provided valuable insights into how investment in TV advertising correlates with sales, offering a data-driven way to make informed marketing decisions!

Key Takeaway: -
Even a simple linear model can yield powerful insights into marketing ROI, helping businesses allocate budgets more effectively.
